# v0.9 Fresh Graph Correctness

v0.9 proves that partial incremental graph updates keep the important graph and query outputs
aligned with a clean full scan.

The release adds four checks:

- stable `graph-snapshot` output
- partial-vs-full mutation-suite equivalence
- evidence freshness propagation
- fresh graph benchmark reporting

Metadata-only eval remains useful for workflow/profile/protocol checks, but it is not treated as
fresh symbol/import/route graph validation.
