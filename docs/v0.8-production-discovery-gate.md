# v0.8 Production Discovery Gate

v0.8 upgrades Discovery Mode from candidate ranking to strict production handoff.

The primary output is `authoritativeHandoff`. Coding agents should read this before any wide lists:

- `mustRead`: verified core files, capped at five.
- `coreChain`: route/page/widget chain evidence.
- `reuseDecision`: whether to reuse, extend, extract, or create.
- `supportingContext`: useful but non-core dependencies, with precise downgrade reasons where available.
- `suppressedCandidates`: why weak matches were removed from the primary context.

Precision-first rules:

- Import-only files cannot enter `mustRead`.
- Supporting dependencies such as l10n, API error wrappers, loggers, auth caches, and generic helpers are downgraded.
- Frontend UI tasks suppress backend, database, infra, screenshot, and E2E noise unless explicitly requested.
- Unverified chains must be labeled `partial_chain` or `candidate_chain`.
- `route_test_covered` is returned only when route/page/widget chain files have related tests.
- Reuse decisions include affected caller paths when the symbol graph can resolve them.
