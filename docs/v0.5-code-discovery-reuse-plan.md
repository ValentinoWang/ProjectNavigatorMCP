# v0.5 Code Discovery & Reuse Intelligence

v0.5 recenters ProjectNavigatorMCP on the original repository-discovery goal:

```text
Find relevant code, entrypoints, callers/callees, reusable implementations, duplicate risks, and impact before an agent edits.
```

## Scope

- Discovery Mode through `discover_code` and `pnav discover`.
- Symbol Model V2 fields and `code_blocks`.
- Call/reference graph V1 through `symbol_edges`.
- Entrypoint discovery for Flutter, FastAPI, commands, tests, and components.
- Reuse and duplicate detection using deterministic fingerprints and token similarity.
- Module maps.
- Why-related evidence chains.
- Impact Analysis V2.

## Non-Goals

- No Postgres.
- No Web UI.
- No autonomous PR workflow.
- No full LSP/SCIP integration.
- No claim of perfect call graph precision.
